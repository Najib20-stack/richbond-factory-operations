# Guide Administrateur

Le compte Administrateur dispose d'une vue globale de l'activité, sans pouvoir
remplacer le vérificateur désigné lors de la décision finale.

## Navigation

- **Tableau de bord** présente tous les indicateurs, les tâches du périmètre et les indices individuels.
- **Tâches** permet de consulter, créer et administrer toutes les tâches.
- **Supervision** centralise les vérifications en attente et la gestion des tâches.
- **Utilisateurs** permet de créer, activer et désactiver les comptes.
- **Rapports** permet de consulter les engagements et d'exporter les données filtrées.
- **Paramètres** contient les départements et l'état des contrôles de sécurité.

## Filtrer le suivi

1. Utiliser la recherche située sous l'en-tête pour chercher un identifiant, un titre, un utilisateur ou un statut.
2. Choisir un département dans le sélecteur adjacent.
3. Consulter les tâches et les indices correspondant au périmètre sélectionné.
4. Utiliser le bouton de réinitialisation pour revenir à la vue globale.

## Gérer les comptes

1. Ouvrir **Utilisateurs**, puis **Créer un utilisateur**.
2. Choisir le rôle, le département et un mot de passe temporaire robuste.
3. Transmettre le mot de passe par un canal interne sécurisé.

Le nouvel utilisateur doit remplacer ce mot de passe à sa première connexion.
Un administrateur ne peut pas désactiver son propre compte.
