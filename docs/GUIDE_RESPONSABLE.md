# Guide du responsable

Le responsable voit uniquement les tâches qui lui sont affectées.

## Parcours d'une tâche

1. Ouvrir **Mon travail** et sélectionner une tâche active.
2. Vérifier les consignes, le lot, la quantité, la ligne et l'échéance.
3. Sélectionner **Démarrer**.
4. Utiliser **Mettre en pause**, **Signaler un problème** ou **Ajouter une note**
   lorsque la situation le nécessite.
5. Utiliser **Demander une nouvelle date** pour justifier une échéance devenue
   impossible.
6. Sélectionner **Terminer** pour envoyer le travail au vérificateur.

Après un refus, la tâche revient à l'état **En cours** avec le motif du
vérificateur. Après validation, elle apparaît dans l'historique terminé.
